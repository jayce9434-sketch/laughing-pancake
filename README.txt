STEAL AN INSECT EGG! — GitHub Edition

HOW TO PLAY
1. Open index.html in a browser, or enable GitHub Pages for the repo.
2. Move with WASD / arrow keys or the on-screen touch controls.
3. Walk near an egg and press E / Space / STEAL-INTERACT.
4. Carry the egg back to your green HOME BASE.
5. Hatch secured eggs from Egg Storage.
6. Select two insects of the same rarity in Collection and fuse them in the DNA Lab.
7. Use the FREE +3000 Rubies button every 3 seconds.

FEATURES
- Top-down explorable map
- Multiple rival insect bases and wild nests
- Egg stealing + carrying + return loop
- Common through Ethereal rarity tiers
- Hatching and insect collection
- DNA fusion with upgrade chances
- Rubies and rewards
- Reusable +3000 Rubies button with a 3-second cooldown
- Rotating live-style events: Egg Rush, DNA Surge, Ruby Rain, Nest Frenzy, Lucky Shells
- Seasonal Halloween and Fall bonuses based on the device date
- Local save data in the browser
- Keyboard + touch controls for iPad/mobile
- Minimap and records

GITHUB
Upload index.html, style.css, game.js, and README.txt to the ROOT of a repository.
For GitHub Pages: Repository Settings -> Pages -> Deploy from branch -> main / root.

No external libraries or assets are required.
